**The docs image is built in CI and pushed to GHCR instead of being built on the deploy host.** The server does not have the RAM to run the docs build next to the other apps. A new `image` job builds and pushes `ghcr.io/awdlab/jig-docs` (`:latest` and `:<sha>`, `linux/amd64`, Actions layer cache) and the SSH deploy step now only pulls and restarts. Auth on both ends is the existing `GITHUB_TOKEN`. No published package changes.
