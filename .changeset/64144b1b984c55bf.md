**The calendar playground drops the input field when `inline` is on.** `JigDocsPlayground` now keeps the values set in its inputs panel as a `values` signal, typed from the `controls` it is given, so a playground template can read `playground.values().JigCalendar?.inline` type-safely. A control swapped in by such a branch gets every panel value re-applied. No published package changes.
