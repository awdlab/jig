**The MCP server starts again.** The entry point imported `./init.js` at the top level, even in server mode. That pulled in `awesome-logging`, which constructs its logger as an import side effect — writing the ANSI hide-cursor escape to stdout, hijacking `console.log`, and calling `process.stdin.setEncoding('utf8')`. The escape corrupted the JSON-RPC channel and the encoding change broke the SDK's inbound parsing, so `initialize` was never answered and every client closed the transport after a few seconds.

`init.js` is now imported lazily inside the `init` branch, so nothing but the server touches stdio in server mode. The `init` CLI is unchanged.
