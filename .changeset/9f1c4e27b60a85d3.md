**The docs app shows a loading indicator wherever it used to wait on a blank area.** A JS-free splash in `index.html` — inline CSS plus the jig mark — paints from the first byte and is retired by a `:has()` rule once the router has rendered a route, so it only ever shows on the client-rendered playground routes; an SSR response paints content before the render-blocking stylesheet lands, so the rule already matches at first paint. Re-appearing is delayed past any route transition, which empties `jig-root` for a frame and otherwise flashed the overlay back in on every navigation, and a 20s animation makes sure the overlay can never trap the page. The same look is reused in the app as `JigDocsLoader`, the jig mark stacked inside `jig-spinner`, and now covers the demo placeholder, the startpage project-board tab and the markdown tabs (API, A11y, i18n), whose host stayed empty for the whole async render on client-side navigation. No published package changes.
