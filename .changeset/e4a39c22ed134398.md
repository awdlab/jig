Publish the built `dist/` manifest instead of the source `package.json`.

These packages were packed with `publishFiles`, which puts the source `package.json` at the
tarball root and leaves the generated manifest nested at `dist/package.json`, where npm never
looks. As published they carried no `exports`, `module` or `typings`, and their
`peerDependencies` still read the unresolved `catalog:` and `workspace:` protocols.

For consumers that meant every `@awdlab/jig/...` import failed to resolve — Node, `tsc`, vitest
and Angular's esbuild bundler alike — and `deno install` refused the tree outright on the
`catalog:` ranges, where pnpm only warns. `dist/package.json` was correct all along; it simply
was not the file being shipped as the manifest. The packages now publish with
`publishDir: 'dist'`. No source or API changes.
