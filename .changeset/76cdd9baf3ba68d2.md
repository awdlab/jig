**Five docs playgrounds now follow the inputs that change how their control is used.** Color picker (`popover`), filter field and filter builder (`mode: 'headless'`) get an anchor button that shows only in that mode; the table renders its selection column only for `selectionMode: 'multi'`; upload shows an "Upload all" button in `manual` mode. Each reads the setting from `playground.values()`. No published package changes.
