Select button is a group of toggle buttons (each using `aria-pressed`), not a
radio group. It uses a roving tabindex so the group is a single tab stop.

## Keyboard

| Key                                                 | Action                                                 |
| --------------------------------------------------- | ------------------------------------------------------ |
| `ArrowRight`/`ArrowLeft` (or `ArrowDown`/`ArrowUp`) | Move focus between options (axis follows orientation). |
| `Home` / `End`                                      | Focus the first / last option.                         |
| `Enter` / `Space`                                   | Toggle the focused option (native button).             |

Disabled options are skipped during navigation.

## ARIA & screen readers

The button group exposes an inner `role="group"` container, and the group host
carries `aria-label`/`aria-labelledby`. Each option is a native `<button>` with
`aria-pressed` reflecting whether it is selected and an `aria-label` from the
item's label; the disabled state uses the native `disabled` attribute. A roving
tabindex keeps one tab stop, with arrow keys moving DOM focus.

Because options are toggle buttons, a screen reader announces "toggle button,
pressed" rather than "radio, selected".

## Developer responsibilities

- Provide `options` (each with a `value` and `label`).
- Give the group an accessible name via `label` or `labelledBy`.
