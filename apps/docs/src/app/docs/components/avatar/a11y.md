Avatar is a presentational control. It is not focusable, has no interactive
behavior, and is treated as decorative by default.

## Keyboard

| Key | Action                                   |
| --- | ---------------------------------------- |
| —   | No keyboard interaction; presentational. |

## ARIA & screen readers

Neither `ngn-avatar` nor `ngn-avatar-group` set a `role` or `aria-*`. The image
branch renders `alt = alt() ?? ''`, so with no `alt` provided the image gets an
empty `alt` and is announced as decorative. The initials branch has no
`alt`/`aria-label` mechanism — the initials text is its only accessible name.

## Developer responsibilities

- Set the `alt` input when the avatar is meaningful (e.g. identifies a person);
  leaving it blank marks the image decorative.
- Initials avatars expose only their initials — add surrounding context where the
  identity matters. There is no `aria-label` input.
