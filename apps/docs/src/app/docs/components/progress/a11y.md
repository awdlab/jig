Progress renders as a `role="progressbar"` carrying the standard value ARIA.

## Keyboard

| Key | Action                                   |
| --- | ---------------------------------------- |
| —   | No keyboard interaction; presentational. |

## ARIA & screen readers

The host is `role="progressbar"` with `aria-valuemin="0"` and `aria-valuemax="100"`
always set. `aria-valuenow` reflects the clamped value in determinate mode and is
dropped in indeterminate mode. No `aria-label` is set.

## Reduced motion

Under `prefers-reduced-motion: reduce` an indeterminate progress indicator
keeps animating at `6s` per cycle. Determinate mode has no loop to slow — its
fill transition still collapses to near-zero, like any other non-looping
animation.

## Developer responsibilities

- Give the bar an accessible name (`aria-label`/`aria-labelledby`) when it needs
  one — the host sets none.
