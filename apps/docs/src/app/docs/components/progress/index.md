The Progress component provides a visual indicator of progress or completion status.

### Basic Usage

The progress displays a value from 0 to 100, showing linear progress.

{{ demo: Demo_Progress_Base }}

### Indeterminate

For operations where progress cannot be determined, use the indeterminate mode which shows an animated progress indicator.

{{ demo: Demo_Progress_Indeterminate }}

### Circular

The progress can also be displayed as a circular indicator.

{{ demo: Demo_Progress_Circular }}

### Circular Indeterminate

The circular progress also supports indeterminate mode with a spinning animation.

{{ demo: Demo_Progress_CircularIndeterminate }}
