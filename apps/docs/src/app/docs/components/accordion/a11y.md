Each accordion panel header is a native `<button>` that controls a
`role="region"` content area, so state and activation are native.

## Keyboard

| Key               | Action                                    |
| ----------------- | ----------------------------------------- |
| `Enter` / `Space` | Toggle the focused panel (native button). |

There is no arrow-key navigation between headers — each header is a normal tab
stop.

## ARIA & screen readers

The header button carries `aria-expanded` and `aria-controls` (pointing at its
content id); the content is `role="region"` with `aria-labelledby` back to the
header and `aria-hidden` while collapsed. The disabled state uses the native
`disabled` attribute.

## Developer responsibilities

- Provide header text (or a `#header` template) so the toggle has an accessible
  name.
- `panelId` is auto-generated if you don't set one; supply a stable one if you
  need deterministic ids.
