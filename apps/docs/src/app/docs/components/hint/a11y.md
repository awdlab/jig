Hint renders helper/validation text and exposes an `id` for a field to reference.
It does not create the association itself — the consuming field points at it.

## Keyboard

| Key | Action                                                                         |
| --- | ------------------------------------------------------------------------------ |
| —   | No keyboard interaction. The icon-only variant shows a tooltip on hover/focus. |

## ARIA & screen readers

The host exposes an `id` (`controlId`, auto-generated) intended for a field's
`aria-describedby`; the hint sets no `aria-describedby` of its own. In the
`iconOnly` variant the text becomes the icon's accessible name via the tooltip
directive. Validation messages are swapped in without an `aria-live` region.

## Developer responsibilities

- Wire the hint's `controlId` into the associated field's `aria-describedby` — the
  hint only exposes the id, it does not connect anything.
- Because message changes are not announced, ensure error state is also conveyed
  through the field itself (e.g. `aria-invalid`).
