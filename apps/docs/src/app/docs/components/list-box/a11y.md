List box is a `role="listbox"` that tracks the highlighted option with
`aria-activedescendant` — focus stays on the listbox host rather than moving to
individual options.

## Keyboard

| Key                     | Action                                                                      |
| ----------------------- | --------------------------------------------------------------------------- |
| `ArrowDown` / `ArrowUp` | Move the highlight by one (wraps at the ends, skips disabled items).        |
| `PageDown` / `PageUp`   | Move the highlight by a visible page's worth of rows, stopping at the ends. |
| `Home` / `End`          | Highlight the first / last enabled option.                                  |
| `Enter` / `Space`       | Select the highlighted option (when `selectable`).                          |

There is no typeahead.

## ARIA & screen readers

The host is `role="listbox"` with `aria-multiselectable` when `multiple`, and
`aria-activedescendant` referencing the highlighted option's id. Leaf items are
`role="option"` with `aria-selected` (only when `selectable`) and `aria-disabled`;
group nodes are `role="group"` with an `aria-label`. The host reflects
`aria-label` from `label` and `aria-labelledby` from `labelledBy`. The empty state
is `role="status"`, and the checkbox indicator is `aria-hidden`/`inert`. The host
is a tab stop when `focussable` (default true).

## Developer responsibilities

- Provide `items`.
- Set `selectable` to expose `aria-selected` on options.
- Give the listbox an accessible name via `label` or `labelledBy`.
