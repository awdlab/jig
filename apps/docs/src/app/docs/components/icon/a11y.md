The icon is decorative by default: the generated `<svg>` is marked
`aria-hidden="true"`, so screen readers ignore it.

## Keyboard

| Key | Action                                   |
| --- | ---------------------------------------- |
| —   | No keyboard interaction; presentational. |

## ARIA & screen readers

The rendered `<svg>` is `aria-hidden="true"`. The host sets no `role="img"` and no
label — the icon is treated purely as decoration.

## Developer responsibilities

- When an icon carries meaning on its own (e.g. an icon-only button), give the
  surrounding interactive element an accessible name (`aria-label` or visible
  text). Do not rely on the icon to convey it.
