### Roles

The projected list is a `role="listbox"` with `role="option"` rows, supplied by
[`jig-list-box`](/components/list-box).

### Naming the list

Set `label` (or `labelledBy`) — it is forwarded to the list box. A listbox without an
accessible name is a WCAG failure, and a standalone dropdown has no surrounding field to borrow
a name from.

```html
<jig-dropdown-list [anchor]="trigger" label="Choose a country" [items]="options" />
```

### Keyboard

The list itself is not a tab stop (`focussable` is off): whatever owns focus drives it. A host
that owns focus — a combobox text field — forwards keys with `onKeyDown()`, and points its own
`aria-activedescendant` at `highlightedOptionId()`.

| Key                     | Behaviour                                 |
| ----------------------- | ----------------------------------------- |
| `ArrowDown` / `ArrowUp` | moves the highlight, wrapping at the ends |
| `Home` / `End`          | jumps to the first / last enabled row     |
| `PageDown` / `PageUp`   | moves by a viewport, stopping at the ends |
| `Enter` / `Space`       | selects the highlighted row               |
| `Escape`                | closes the list                           |

`Home` and `End` stay with the caret while a text field driving the list has content, so typing
is never hijacked.

### Ids

The list box is `{inputId}_listbox` and the popover `{inputId}_popover`, so a host can reference
them without reaching into the DOM.
