`ngnNumberInput` is a directive on a native `<input>`, turning it into a
`role="spinbutton"` with `inputmode="decimal"`. It keeps native text entry and
adds arrow-key stepping.

## Keyboard

| Key                     | Action                                                            |
| ----------------------- | ----------------------------------------------------------------- |
| `ArrowUp` / `ArrowDown` | Step the value up/down by `step` (hold `Shift` for the big step). |
| `Enter`                 | Commit the current value (before form submit).                    |

Stepping clamps to `min`/`max` and does not wrap; `Alt`/`Ctrl`/`Meta` + arrow
fall through to native behavior.

## ARIA & screen readers

The directive sets `role="spinbutton"` with `aria-valuenow`, and
`aria-valuemin`/`aria-valuemax` when `min`/`max` are set. `aria-label` comes from
the `label` input, and `aria-invalid="true"` is set when `invalid`.
Disabled/readonly use the native `disabled`/`readOnly` properties. The directive
does **not** support `aria-labelledby`.

## Developer responsibilities

- Name the field via `label` (`aria-labelledby` is not supported by the
  directive) — or use it inside an `awd-input-field`.
