Item view is a horizontal list with overflow handling. It uses real list
semantics (`role="list"`), so items are announced as a list.

## Keyboard

| Key | Action                                 |
| --- | -------------------------------------- |
| —   | No keyboard interaction; display only. |

## ARIA & screen readers

The host is `role="list"` and each item is `role="listitem"`; the overflow
indicator is `aria-hidden` while not visible.

## Developer responsibilities

- Provide `idField` and `items`.
- `sameWidthItems` is a performance option — it measures only the first item and
  assumes that width for the rest. It does **not** change accessibility:
  overflowed items are still emitted as `role="listitem"` and the overflow
  indicator still reports the hidden count. Its only caveat is correctness — use
  it only when the items really are the same width, or the visible/overflow split
  will be wrong.
