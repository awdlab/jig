Popover is a thin positioning container built on the native Popover API. It sets
no role, no label, and no focus management of its own — the projected content owns
its semantics.

## Keyboard

| Key      | Action                                                                                              |
| -------- | --------------------------------------------------------------------------------------------------- |
| `Escape` | Closes the popover when `closeBy` allows light-dismiss (`auto` mode); in `manual` mode it does not. |

## ARIA & screen readers

The overlay is a roleless, unlabeled container using the native `popover`
attribute — no `role`, no `aria-modal`, and no focus trap. Native `popover="auto"`
does not move focus in or trap `Tab`.

## Developer responsibilities

- Give the projected content its own semantics: a `role` (e.g. `dialog`/`menu`),
  an accessible name, and focus management/trapping if it should behave modally.
  The popover provides none of these.
- Choose `closeBy` to control whether `Escape` and outside-click dismiss it.
