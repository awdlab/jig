State is an inline status indicator. Because its kind is conveyed visually through
icon shape and color, it also announces itself through a live region when a known
kind is applied and the indicator is visible.

## Keyboard

| Key | Action                                   |
| --- | ---------------------------------------- |
| —   | No keyboard interaction; presentational. |

## ARIA & screen readers

When visible with a known kind, the host becomes a live region: `role="alert"` +
`aria-live="assertive"` for `error`/`warning`, otherwise `role="status"` +
`aria-live="polite"`, with `aria-atomic="true"` and a visually-hidden localized
label. While hidden or without a known kind, the host is a plain, roleless span.
The icons are `aria-hidden`.

## Developer responsibilities

- Set `kind` — it drives whether and how the indicator announces.
- Optionally override the politeness with `ariaLive` (`polite`/`assertive`/`off`)
  and the announced text with `label` (e.g. `"Saving…"`).
- Provide the i18n strings for the default kind labels.
