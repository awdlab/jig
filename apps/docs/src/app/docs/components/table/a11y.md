The table exposes an ARIA grid over native table elements. It has a single tab
stop on the table host; arrow keys move a visual "current row" highlight rather
than moving DOM focus cell-by-cell. Which keys are active depends on whether
selection and row actions are enabled.

## Keyboard

| Key                           | Action                                                                                                                                                                    |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ArrowDown` / `ArrowUp`       | Move the current row. In single-select mode selection follows the current row; in multi-select the highlight moves only (hold `Shift` to extend a range from the anchor). |
| `Space` / `Enter`             | Multi-select: toggle the current row's selection.                                                                                                                         |
| `ArrowRight`                  | Move into the current row's inline action bar, then between action buttons.                                                                                               |
| `ArrowLeft`                   | Move to the previous action; past the first, exit the bar back to the row.                                                                                                |
| `Enter`                       | With no selection mode and focus on a row: open the row's context menu.                                                                                                   |
| `ContextMenu` / `Shift`+`F10` | Open the current row's context menu.                                                                                                                                      |
| `Escape`                      | Exit the action bar back to the row.                                                                                                                                      |

Group headers expand/collapse on click only — there is no keyboard toggle.

## ARIA & screen readers

Roles come from the table and its directives: `grid`, `rowgroup`, `row`,
`columnheader`, and `gridcell`. The grid sets `aria-multiselectable` in
multi-select mode and `aria-rowcount` (which excludes the header row and includes
group-header rows); each row carries `aria-rowindex` (header row = 1). Rows expose
`aria-selected` when a selection mode is active, sortable headers expose
`aria-sort`, and the built-in group-header rows expose `aria-expanded`. Inline
action buttons get `aria-haspopup="menu"` when they have children, and selection
checkboxes get localized labels. A visually-hidden `aria-live="polite"` region
announces sort, filter, pagination, and selection changes (e.g. "Sorted by name,
ascending", "12 results", "Page 2 of 5", "3 of 40 selected").

## Developer responsibilities

- Apply the row/cell directives (`ngnTableHeadTr`, `ngnTableBodyTr`, `ngnTableTh`,
  `ngnTableTd`) — the grid roles come from them.
- Provide column header text and an accessible name for the grid (`aria-label`);
  none is set by default.
- A custom `#groupHeader` template receives no roles or `aria-expanded` — supply
  `role="row"`, `role="gridcell"`, and `aria-expanded` yourself. Only the built-in
  default group row provides them.
