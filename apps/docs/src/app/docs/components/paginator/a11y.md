Paginator is built from native `<button>` elements, so activation and focus are
native.

## Keyboard

| Key                    | Action                                                                          |
| ---------------------- | ------------------------------------------------------------------------------- |
| `Enter` / `Space`      | Activate the focused button (native).                                           |
| `Shift`/`Ctrl` + click | On previous/next, jump 10 / 100 pages (pointer modifiers, not standalone keys). |

There is no arrow-key navigation between the page buttons.

## ARIA & screen readers

The previous/next buttons carry localized `aria-label`s, and the active page
button is marked `aria-current="page"`; the other page buttons are named by their
visible number. The paginator host has no landmark role.

## Developer responsibilities

- Wrap the paginator in a labelled `<nav>` if you want a navigation landmark — the
  control provides none.
- Provide the paginator i18n strings.
