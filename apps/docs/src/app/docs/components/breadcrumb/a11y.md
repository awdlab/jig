Breadcrumb is a labelled `role="navigation"` landmark containing the trail (with
an optional overflow menu). Each crumb renders as the element its data calls for,
so navigation and activation stay native.

## Keyboard

| Key               | Action                                                                      |
| ----------------- | --------------------------------------------------------------------------- |
| `Enter`           | Activate the focused crumb link (native `<a>`).                             |
| `Enter` / `Space` | Activate a crumb that only has a `callback` (native `<button>`).            |
| `Enter` / `Space` | Open the overflow menu button; the menu then uses its own keyboard pattern. |

## ARIA & screen readers

The host carries `role="navigation"` and a localized `aria-label` ("Breadcrumb"),
overridable with `label` or `labelledBy`. The overflow button has its own
localized `aria-label`.

Crumbs render by capability, so nothing is announced as a link that cannot be
followed:

| Item has            | Element    | Notes                            |
| ------------------- | ---------- | -------------------------------- |
| `route`             | `<a>`      | A real link, with an `href`.     |
| `callback` only     | `<button>` | Focusable and keyboard-operable. |
| neither, or is last | `<span>`   | Not interactive.                 |

The last item is the current page: it carries `aria-current="page"` and is never
rendered as a link or button, whatever `route`/`callback` it declares.

## Developer responsibilities

- Provide `items` ordered root → current. The last entry is treated as the
  current page.
- Give `label` or `labelledBy` a distinct value when a page has more than one
  breadcrumb landmark.
