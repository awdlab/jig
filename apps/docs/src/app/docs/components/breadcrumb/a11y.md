Breadcrumb renders its trail as native links (with an optional overflow menu), so
navigation and activation are native.

## Keyboard

| Key               | Action                                                                      |
| ----------------- | --------------------------------------------------------------------------- |
| `Enter`           | Activate the focused breadcrumb link (native `<a>`).                        |
| `Enter` / `Space` | Open the overflow menu button; the menu then uses its own keyboard pattern. |

## ARIA & screen readers

The overflow button has a localized `aria-label`. The current page (the last item
with no route/callback) is distinguished visually only.

## Developer responsibilities

- Provide `items` ordered root → current; the last item with no `route`/`callback`
  is treated as the current page.
- The control ships **no** `<nav>` landmark and **no** `aria-current` on the
  current page — wrap it in a labelled `<nav>` and mark the current crumb yourself
  if you need the full WAI-ARIA breadcrumb semantics.
