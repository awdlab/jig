Message is a persistent, inline severity indicator meant to be read in place — it
is not a live region and has no interactive behavior.

## Keyboard

| Key | Action                                 |
| --- | -------------------------------------- |
| —   | No keyboard interaction; display only. |

## ARIA & screen readers

The message sets no `role` and no `aria-live` — it is not announced. Its severity
is conveyed visually through `color` and an optional icon.

## Developer responsibilities

- Convey the severity in the text as well; color and icon alone are not exposed to
  assistive tech.
- The message host has no `role`. Add one for the context — e.g. `role="note"`,
  or `role="status"`/`"alert"` (with `aria-live`) if it should be announced when it
  appears. The component sets none by design.
- For transient or urgent announcements, use `snackbar` or `toast` (which are live
  regions) instead of `message`.
