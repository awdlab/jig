`ngnInput` is an attribute directive on a native `<input>` or `<textarea>`. It
keeps the element's native semantics and keyboard behavior, adding only the
validation ARIA.

## Keyboard

| Key                   | Action                                                                        |
| --------------------- | ----------------------------------------------------------------------------- |
| Standard editing keys | Native `<input>` / `<textarea>` behavior; the directive adds no key handling. |

## ARIA & screen readers

The directive sets `aria-invalid="true"` when its `invalid` input is set (and
removes it otherwise). It does no labelling — screen readers rely on the native
element and whatever label the consumer provides.

## Developer responsibilities

- Associate a label yourself: a `<label for>`, `aria-label`, or `aria-labelledby`.
  The directive provides none.
