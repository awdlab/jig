The tooltip renders as `role="tooltip"` via the native Popover API and
automatically wires the association ARIA onto its anchor element. It never takes
focus — it is a hint, shown on hover or focus of the anchor.

## Keyboard

| Key      | Action                               |
| -------- | ------------------------------------ |
| `Escape` | Hides the tooltip while it is shown. |

Otherwise the tooltip shows/hides via hover and anchor focus/blur.

## ARIA & screen readers

The tooltip host is `role="tooltip"` and gets `aria-hidden` while not shown. The
anchor's ARIA is managed by `autoAriaMode` (default `description`): with string
content it is associated via `aria-describedby`/`aria-labelledby` (by id) while
shown, and falls back to `aria-description`/`aria-label` (by value) while hidden.
Setting `autoAriaMode="none"` disables all of this.

## Developer responsibilities

- Usually nothing — the anchor association is automatic.
- Set `autoAriaMode="none"` and wire your own ARIA if the default association is
  unwanted.
- With `TemplateRef` content, the anchor has no accessible text while the tooltip
  is hidden; supply your own label if that matters.
