Snackbars are live-region notifications. The politeness is derived from the
snackbar's color, and the host region supports keyboard roving between snackbars.

## Keyboard

| Key                     | Action                                |
| ----------------------- | ------------------------------------- |
| `Escape`                | Dismiss a closable snackbar.          |
| `F6`                    | Jump focus to the newest snackbar.    |
| `ArrowUp` / `ArrowDown` | Move between snackbars in the region. |
| `Home` / `End`          | Focus the first / last snackbar.      |

## ARIA & screen readers

Each snackbar is `role="alert"` with `aria-live="assertive"` for `error`/`warning`
colors, otherwise `role="status"` with `aria-live="polite"`; `aria-atomic="true"`
is always set. A visually-hidden severity prefix conveys the color's meaning. The
close button has a localized `aria-label`, and icons/progress are `aria-hidden`.
The container is a labelled `role="region"` with a roving tabindex across items.
The auto-hide timer pauses while a snackbar is focused (always) or hovered (with
`pauseOnHover`).

## Reduced motion

Under `prefers-reduced-motion: reduce` the snackbar's enter and leave
animations collapse, but the countdown bar keeps its exact duration — it
reports the remaining time before auto-hide. Setting `disableAnimations: true`
does override it, and the bar then empties immediately.

## Developer responsibilities

- Pick a `color` (drives politeness) or override it with `ariaLive`.
- Provide the snackbar i18n strings (close label, region label, severity labels).
- Focus returns to the previously focused element automatically on close.
