Button group is a layout-and-focus wrapper: it exposes a `role="group"` container
and gives the buttons a single tab stop via a roving tabindex.

## Keyboard

| Key                                                 | Action                                                 |
| --------------------------------------------------- | ------------------------------------------------------ |
| `ArrowRight`/`ArrowLeft` (or `ArrowDown`/`ArrowUp`) | Move focus between buttons (axis follows orientation). |
| `Home` / `End`                                      | Focus the first / last button.                         |
| `Enter` / `Space`                                   | Activate the focused button (native).                  |

Disabled buttons are skipped; movement stops at the ends (no wrapping).

## ARIA & screen readers

The inner container is `role="group"`, with a roving tabindex so `Tab` enters and
leaves the group as one unit. No `aria-orientation` is set on the container.

## Developer responsibilities

- Provide `button[ngnButton]` or `ngn-toggle-button` children.
- Give the group an accessible name yourself — the control wires no
  `aria-label`/`aria-labelledby`.
