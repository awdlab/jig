### Roles & Attributes

The directive adds no roles or ARIA attributes — it only writes position
styles. Whatever the host means semantically is unchanged by making it
draggable.

### Keyboard Interaction

**None.** Dragging is pointer-only: there is no keyboard equivalent, and the
host does not become focusable.

That is acceptable only when moving the element is a **convenience, not a
requirement** — repositioning a dialog so it stops covering the row behind it,
nudging a floating panel out of the way. If a user who cannot drag ends up
unable to complete the task, the pattern fails
[WCAG 2.1.1 Keyboard](https://www.w3.org/WAI/WCAG22/Understanding/keyboard.html).

Keep the underlying task reachable without dragging:

- never place content only reachable by moving something out of the way;
- provide a reset ("center", "restore position") where the element can be
  dragged off-screen;
- do not use dragging to submit, choose, or reorder anything meaningful —
  those need a keyboard path.

### Pointer Gestures

The drag is a single-pointer gesture with no path requirement, satisfying
[WCAG 2.5.1 Pointer Gestures](https://www.w3.org/WAI/WCAG22/Understanding/pointer-gestures.html).

Dragging is a "dragging movement" under
[WCAG 2.5.7 Dragging Movements](https://www.w3.org/WAI/WCAG22/Understanding/dragging-movements.html)
(AA in WCAG 2.2), which requires a single-pointer alternative that is not a
drag — unless the dragging is essential. Treat the guidance above as the way to
meet it: keep the outcome achievable without the drag.

### Target Size

When you supply an `ngnMovableDragHandle`, size it at least 24×24 CSS pixels to
meet [WCAG 2.5.8 Target Size (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html).
A thin title strip is a common failure.

### Touch

The directive calls `preventDefault()` on `touchmove` over the host while
enabled, so a drag does not scroll the page underneath. That also means the
host itself cannot be touch-scrolled while it is movable — use a handle if the
host has scrollable content.
