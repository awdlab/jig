`ngn-otp` is a `role="group"` wrapping one native `<input maxlength="1">` per
character cell. Each cell is individually focusable and selects its content on
focus, so typing always overwrites the active cell.

## Keyboard

| Key                        | Action                                                                    |
| -------------------------- | ------------------------------------------------------------------------- |
| Character key              | Fills the active cell and advances focus to the next cell.                |
| `Backspace`                | Clears the active cell, or steps back and clears the previous when empty. |
| `Delete`                   | Clears the active cell.                                                   |
| `ArrowLeft` / `ArrowRight` | Move focus to the previous / next cell.                                   |
| `Home` / `End`             | Move focus to the first / last cell.                                      |
| Paste                      | Distributes the pasted characters across the cells from the start.        |

`Ctrl`/`Meta`/`Alt` + key combinations fall through so browser paste and other
shortcuts keep working.

## ARIA & screen readers

The host carries `role="group"`; name it with the `label` input (exposed as the
group's `aria-label`) or `labelledBy` (`aria-labelledby`). `aria-invalid="true"`
is mirrored on the group and every cell when `invalid` is set.

Each cell is labelled by its position via the translatable `otp.cellLabel`
string (e.g. "Character 3 of 6"), and the first cell advertises
`autocomplete="one-time-code"` so mobile browsers can offer SMS-code autofill.

## Developer responsibilities

- Always name the field via `label` or `labelledBy`.
- Use `integerOnly` for numeric codes so the correct on-screen keyboard appears.
