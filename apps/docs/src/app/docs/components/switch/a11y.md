The switch renders a real native `<input type="checkbox">` — it is announced as a
checkbox, not a `role="switch"`. State and keyboard behavior come from the
browser.

## Keyboard

| Key     | Action                                      |
| ------- | ------------------------------------------- |
| `Space` | Toggles the switch (native input behavior). |

Both `readonly` and `disabled` block toggling — the native `Space` press becomes
a `click`, which the control's guard cancels.

## ARIA & screen readers

ARIA is set on the native input: `aria-readonly` when `readonly`,
`aria-invalid="true"` when `invalid`, `aria-label` from `label`, and
`aria-labelledby` from `labelledBy`. Checked state uses the native `checked`
property (not `aria-checked`), and the disabled state uses the native `disabled`
attribute.

## Developer responsibilities

- Provide an accessible name via `label` (→ `aria-label`) or `labelledBy`
  (→ `aria-labelledby`) — neither is set by default, so the switch is otherwise
  unnamed.
