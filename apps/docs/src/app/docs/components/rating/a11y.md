Rating is a `role="slider"` widget: the host is focusable and carries the value
ARIA.

## Keyboard

| Key                       | Action                          |
| ------------------------- | ------------------------------- |
| `ArrowLeft` / `ArrowDown` | Decrease the value by one step. |
| `ArrowRight` / `ArrowUp`  | Increase the value by one step. |
| `Home`                    | Jump to the minimum (0).        |
| `End`                     | Jump to the maximum (`count`).  |

Keys are ignored when `readonly` or `disabled`.

## ARIA & screen readers

The host is `role="slider"` with `aria-valuemin="0"`, `aria-valuemax` (`count`),
and `aria-valuenow` (`value`) always set. `aria-valuetext` is emitted only when
`valueText` or `valueTextFn` is provided. It also reflects `aria-readonly` when
readonly and `aria-label`/`aria-labelledby` from its inputs; `tabindex` is `0`
(or `-1` when disabled).

## Developer responsibilities

- Provide an accessible name via `label` or `labelledBy`.
- Provide `valueText` or `valueTextFn` when the raw number is not meaningful on
  its own (e.g. "3 out of 5 stars") — otherwise `aria-valuetext` is absent.
- When using a custom `indicatorTemplate`, keep the rendered symbol
  decorative — the accessible value is carried by the host's ARIA, not by
  the symbol markup.
