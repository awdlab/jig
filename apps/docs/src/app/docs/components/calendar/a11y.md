The day grid is a set of native `<button>` elements with a roving tabindex and
arrow-key navigation. The month/year controls and (in popup mode) the input are
standard labelled controls.

## Keyboard

| Key                        | Action                                                                  |
| -------------------------- | ----------------------------------------------------------------------- |
| `ArrowLeft` / `ArrowRight` | Move to the previous / next day (pages to the adjacent month at edges). |
| `ArrowUp` / `ArrowDown`    | Move by one week back / forward (pages months on overflow).             |
| `Enter` / `Space`          | Select the focused day (native button).                                 |
| `Enter` (popup mode)       | Toggle the popup open/closed.                                           |

`Home`/`End` and `PageUp`/`PageDown` are not handled.

## ARIA & screen readers

The day grid is `role="grid"`, labelled with the visible month and year; each
weekday header is a `role="columnheader"`, each week a `role="row"`, and each day
a `role="gridcell"`. The selected day exposes `aria-selected`, today is marked
`aria-current="date"`, and every day button has the full localized date as its
`aria-label` (e.g. "Thursday, 15 January 2026") so the number is never announced
without context. The host reflects `aria-invalid` when invalid; the prev/next
month buttons, the month `<select>`, and the year input carry localized labels; a
roving tabindex keeps one day focusable at a time. There is no live region.

## Developer responsibilities

- Provide the i18n translations — the control's labels are only as good as those.
- Label the overall field/popup externally if needed. The day grid names itself
  from its month and year, but the control host has no accessible name of its own.
