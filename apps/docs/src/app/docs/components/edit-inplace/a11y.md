Edit inplace shows a value that turns into an input field when activated. The
input autofocuses on open, and committing returns to the display view.

## Keyboard

| Key               | Action                                                    |
| ----------------- | --------------------------------------------------------- |
| `Enter` / `Space` | Open the editor from the display trigger (native button). |
| `Enter` (editing) | Commit the value and return to the display view.          |

There is no `Escape`-to-cancel; committing (Enter) or moving focus away applies
the value.

## ARIA & screen readers

The confirm button has a localized `aria-label`, and the editor is an
`awd-input-field` (with `label`/`labelledBy` forwarded). The display view includes
a visually-hidden label echoing the placeholder. The toggle exposes no
`aria-expanded`/`aria-controls`.

## Developer responsibilities

- Provide `value` and `label`; supply the edit-inplace i18n strings.
- Note that `Escape` does not cancel — the value commits on `Enter` or blur.

## Focus

The input autofocuses when the editor opens (`ngnAutofocus`); moving focus out of
the control returns to the display view, and closing returns focus to the trigger.
