Tabs follow the WAI-ARIA tabs pattern with **manual activation**: arrow keys move
focus between headers, and the focused tab is only activated on `Enter`/`Space`.

## Keyboard

| Key                        | Action                                                 |
| -------------------------- | ------------------------------------------------------ |
| `ArrowLeft` / `ArrowRight` | Moves focus between tab headers, wrapping at the ends. |
| `Enter` / `Space`          | Activates the focused tab.                             |

`Home`/`End` are not handled.

## ARIA & screen readers

The header container is `role="tablist"`, each header is `role="tab"`, and each
panel is `role="tabpanel"`. The active tab carries `aria-selected`; tabs link to
their panels with `aria-controls`, and panels link back with `aria-labelledby`.
A roving tabindex gives the tablist a single tab stop (active tab `tabindex="0"`,
the rest `-1`); the scroll-arrow buttons are excluded from the tab order.

## Developer responsibilities

- Provide header content per tab — it is the accessible label of the tab button.
- Supply a `tabId` for each `<awd-tab>`.
- The tablist itself has no accessible name; add one if the tab set needs to be
  distinguishable.
