The drawer is a panel built on the native Popover API. When `modal`, it is a
`role="dialog"` with `aria-modal` and a focus trap; otherwise it is a
`role="complementary"` region with no trapping.

## Keyboard

| Key                   | Action                                                           |
| --------------------- | ---------------------------------------------------------------- |
| `Escape`              | Closes the drawer (native Popover light-dismiss, per `closeBy`). |
| `Tab` / `Shift`+`Tab` | Wraps focus within a modal drawer (focus trap).                  |

## ARIA & screen readers

A modal drawer is `role="dialog"` with `aria-modal="true"`; a non-modal drawer is
`role="complementary"` with no `aria-modal`. `aria-labelledby` points at the
header id **only when a `header` is set** (it is `null` otherwise — no dangling
reference). The default header's close button has a localized `aria-label`.

## Developer responsibilities

- Provide a `header` for an automatic accessible name; with a custom header or a
  non-modal drawer, supply a name yourself.
- Set `modal` when you need dialog semantics — `role="dialog"`, `aria-modal`, and
  the focus trap (which moves focus in on open and returns it to the opener on
  close). A non-modal drawer does neither.
