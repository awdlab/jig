Toggle button is a native `<button>` that reports its on/off state with
`aria-pressed`. Keyboard and focus are native.

## Keyboard

| Key               | Action                                 |
| ----------------- | -------------------------------------- |
| `Enter` / `Space` | Toggle the button (native activation). |

When `readonly`, the button stays focusable and activatable but the toggle is a
no-op; use `disabled` to remove it from interaction entirely.

## ARIA & screen readers

The button carries `aria-pressed` bound to its value, plus `aria-label`/
`aria-labelledby` from its inputs. The disabled state uses the native `disabled`
attribute; the `invalid` input only drives styling and sets no `aria-invalid`.

## Developer responsibilities

- Give the button an accessible name — projected text (`labelOn`/`labelOff`/
  `label`) or the `label` input. An icon-only toggle must set `label`.
- Prefer `disabled` over `readonly` when the button should not respond to the
  keyboard — `readonly` still presents as actionable.
