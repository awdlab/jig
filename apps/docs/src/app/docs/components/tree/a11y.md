Tree implements the WAI-ARIA `tree` pattern with an active-descendant model —
focus stays on the tree host while the highlighted node is tracked via
`aria-activedescendant`.

## Keyboard

| Key                     | Action                                                        |
| ----------------------- | ------------------------------------------------------------- |
| `ArrowDown` / `ArrowUp` | Move the highlight (wraps at the ends, skips disabled nodes). |
| `ArrowRight`            | Expand a collapsed branch, else move to its first child.      |
| `ArrowLeft`             | Collapse an expanded branch, else move to the parent.         |
| `Home` / `End`          | Highlight the first / last node.                              |
| `Enter` / `Space`       | Select the highlighted node.                                  |
| type a character        | Jump to the next node whose label starts with it (typeahead). |

## ARIA & screen readers

The host is `role="tree"` with `aria-activedescendant` and `aria-multiselectable`.
Each `role="treeitem"` carries `aria-level`, `aria-setsize`, `aria-posinset`,
`aria-expanded` (branches), and either `aria-selected` (selection without
checkboxes) or `aria-checked` (checkbox mode), plus `aria-disabled`. Toggle and
checkbox visuals are `aria-hidden`, and the empty state is `role="status"`. The
host also reflects `aria-label` from `label` and `aria-labelledby` from
`labelledBy`.

## Developer responsibilities

- Provide `items` with a `label` (drives typeahead and the default rendering) and
  a `value`; supply `itemHeight` when `virtual`.
- Give the tree an accessible name via `label` or `labelledBy`.
