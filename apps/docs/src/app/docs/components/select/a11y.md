Select implements the ARIA combobox + listbox pattern. The trigger is a combobox
that controls a listbox popup, and the highlighted option is tracked with
`aria-activedescendant` rather than by moving DOM focus.

## Keyboard

| Key                     | Action                                                                  |
| ----------------------- | ----------------------------------------------------------------------- |
| `Enter`                 | Opens/closes the dropdown; when open, selects the highlighted option.   |
| `ArrowDown` / `ArrowUp` | Moves the highlighted option (wraps at the ends, skips disabled items). |
| `Space`                 | Selects the highlighted option.                                         |

There is no `Home`/`End` or typeahead. Closing on `Escape` is handled by the
popover overlay.

## ARIA & screen readers

The trigger carries `role="combobox"`, `aria-haspopup="listbox"`, `aria-expanded`,
and `aria-controls` pointing at the listbox. It also reflects `aria-invalid` when
invalid, `aria-readonly` when readonly, and `aria-label`/`aria-labelledby` from
its inputs. The dropdown is `role="listbox"` with `aria-multiselectable` in
multiple mode and `aria-activedescendant` referencing the highlighted option.
Options are `role="option"` with `aria-selected` and `aria-disabled`; the
empty/no-results state is `role="status"`, and the filter input has a localized
`aria-label`.

## Developer responsibilities

- Provide an accessible name via `label` or `labelledBy` — otherwise the combobox
  is unnamed.
- Give each option a meaningful label.
- In editable mode with a custom projected `jigInput`, the control adds the
  combobox ARIA to your input automatically.
