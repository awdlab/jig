Input field is a composition wrapper: it renders a `<label>` and associates it
with the projected input via a generated `id`/`for` pair. It adds no semantics of
its own to the input beyond labelling.

## Keyboard

| Key | Action                                                                        |
| --- | ----------------------------------------------------------------------------- |
| —   | No keys of its own; clicking the field forwards focus to the projected input. |

## ARIA & screen readers

The `<label>` names the projected control through [`jigFor`](/components/label):
it points at the control's own `inputId` and puts its id first in the control's
`aria-labelledby`, followed by any ids from the field's `labelledBy`. This works
the same for a native input, a select, a calendar or a tag-input. The clear
button has a localized `aria-label`, and the host becomes `inert` when disabled.
The wrapper does **not** set `aria-invalid`/`aria-readonly`/`aria-disabled` — its
`invalid`/`readonly`/`disabled` inputs only toggle styling. A projected jig
control reports its own gated invalid state to the field, which styles its
chrome from it; for readonly the theme reads the `aria-readonly` you set on the
input itself.

## The id

The control keeps its own id — an `id` on a `jigInput`, or `inputId` on any
other control — and the field label follows it. Set it on the control when an
external `<label for>` (or `aria-controls`/`aria-describedby`) has to reference
it:

```html
<label for="login-username">Username</label>
<jig-input-field>
  <input jigInput id="login-username" autocomplete="username" />
</jig-input-field>
```

When the projected content isn't a jig control — a custom `role="button"`, say —
give it an id and point the label at it with `labelFor`.

## Developer responsibilities

- Project the actual `input`/`textarea`.
- Provide a `label` (otherwise no `<label>` renders) or an external `labelledBy`.
- Set `aria-invalid`/`aria-readonly` on your own input when those states should
  reach assistive tech — the wrapper only styles them.
