Upload is a dropzone layered over a consumer-projected native `<input type="file">`
— that input is the real, focusable control, so picker activation and focus are
native.

## Keyboard

| Key               | Action                                                          |
| ----------------- | --------------------------------------------------------------- |
| `Enter` / `Space` | Open the file picker (native file input, overlaid on the zone). |

Per-item upload/retry/cancel/remove controls are native `<button>`s.

## ARIA & screen readers

The native file input is labelled via `aria-labelledby` pointing at the projected
placeholder, and it is kept accessible (not `aria-hidden`). The progress bar and
each per-item action button carry localized `aria-label`s. The focus ring is
surfaced on the zone via `:has(:focus-visible)` since focus lives on the input,
whose `tabindex` toggles with the `clickable`/`disabled` state.

## Developer responsibilities

- Project the `<input type="file">` (with `accept`/`multiple`/`name`); the control
  discovers and drives it, and you run the transfer and report progress.
- Provide the placeholder content — it names the input — and the upload i18n
  strings.
