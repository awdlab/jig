Tag is a display-only control — it carries no click, close, or focus behavior and
is not interactive.

## Keyboard

| Key | Action                                 |
| --- | -------------------------------------- |
| —   | No keyboard interaction; display only. |

## ARIA & screen readers

The tag sets no `role` or `aria-*`. Its optional leading icon is decorative; the
tag's meaning comes from its projected text content.

## Developer responsibilities

- Ensure the tag's text conveys its meaning, since there is no interactive
  semantics to expose.
- The tag host has no `role`. If a tag conveys status that should be announced (or
  is a semantic item in a larger widget), add an appropriate `role` yourself — the
  component sets none.
