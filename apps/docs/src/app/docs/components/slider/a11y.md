The slider is a `role="slider"` widget with the full value ARIA and keyboard
stepping. In single-value mode the host element itself is focusable and carries
the state; in `range` mode the host degrades to `role="group"` and each of the two
handles becomes its own focusable `role="slider"`, per the WAI-ARIA APG
multi-thumb pattern.

## Keyboard

| Key                       | Action                                    |
| ------------------------- | ----------------------------------------- |
| `ArrowLeft` / `ArrowDown` | Decrease the value by one step.           |
| `ArrowRight` / `ArrowUp`  | Increase the value by one step.           |
| `Home`                    | Jump to the handle's lowest legal value.  |
| `End`                     | Jump to the handle's highest legal value. |

In `range` mode the keys act on the focused handle only, and `Home`/`End` respect
`minRangeDistance` — they land on `other ∓ minRangeDistance`, not on `min`/`max`.
Tab moves between the two handles.

`PageUp`/`PageDown` are not handled. Keys are ignored when `readonly` or
`disabled`.

## ARIA & screen readers

|                      | single value                                                        | `range`                                                                                                 |
| -------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| host role            | `slider`                                                            | `group`                                                                                                 |
| host `tabindex`      | `0`, or `-1` when disabled                                          | absent                                                                                                  |
| host value ARIA      | `aria-valuemin`/`-valuemax`/`-valuenow`/`-valuetext`/`-orientation` | absent                                                                                                  |
| host name            | `aria-label` / `aria-labelledby`                                    | `aria-label` / `aria-labelledby`, naming the group                                                      |
| host `aria-readonly` | when `readonly`                                                     | absent                                                                                                  |
| `disabled` attribute | when `disabled`                                                     | when `disabled`                                                                                         |
| handles              | no ARIA, not focusable                                              | each `role="slider"` with its own `tabindex`, value ARIA, `aria-orientation`, `aria-readonly`, and name |

`aria-valuetext` is emitted only when `valueText` or `valueTextFn` is provided; in
`range` mode a static `valueText` applies to both handles while `valueTextFn` is
evaluated per handle.

Range handle `aria-valuemin`/`aria-valuemax` report that handle's own legal
window — including `minRangeDistance` — rather than the full track, so assistive
tech announces the limit the user will actually hit.

Handle names come from the `slider.rangeStart` / `slider.rangeEnd` i18n keys.

## Developer responsibilities

- Provide an accessible name via `label` or `labelledBy`. In `range` mode this
  names the group; the individual handles are named from i18n.
- Provide `valueText` or `valueTextFn` when the raw number is not meaningful on
  its own (e.g. "$20", "Medium") — otherwise `aria-valuetext` is absent.
