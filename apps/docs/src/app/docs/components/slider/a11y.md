The slider is a `role="slider"` widget with the full value ARIA and keyboard
stepping. The host element itself is focusable and carries the state.

## Keyboard

| Key                       | Action                          |
| ------------------------- | ------------------------------- |
| `ArrowLeft` / `ArrowDown` | Decrease the value by one step. |
| `ArrowRight` / `ArrowUp`  | Increase the value by one step. |
| `Home`                    | Jump to the minimum.            |
| `End`                     | Jump to the maximum.            |

`PageUp`/`PageDown` are not handled. Keys are ignored when `readonly` or
`disabled`.

## ARIA & screen readers

The host is `role="slider"` with `aria-valuemin`, `aria-valuemax`, and
`aria-valuenow` always set, plus `aria-orientation`. `aria-valuetext` is emitted
only when `valueText` or `valueTextFn` is provided. It also reflects
`aria-readonly` when readonly and `aria-label`/`aria-labelledby` from its inputs;
`tabindex` is `0` (or `-1` when disabled).

## Developer responsibilities

- Provide an accessible name via `label` or `labelledBy`.
- Provide `valueText` or `valueTextFn` when the raw number is not meaningful on
  its own (e.g. "$20", "Medium") — otherwise `aria-valuetext` is absent.
