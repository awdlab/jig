Scroller is a virtualized scroll container. It is presentational — it applies no
list semantics of its own — and is keyboard-scrollable only when made focusable.

## Keyboard

| Key        | Action                                                                 |
| ---------- | ---------------------------------------------------------------------- |
| Arrow keys | Native scrolling, when the scroller is `focusable` (in the tab order). |

## ARIA & screen readers

The scroller sets no `role` or `aria-*`; rows receive only theme classes via
`ngnScrollerItem`. The host is a tab stop (`tabindex="0"`) when `focussable`.

## Developer responsibilities

- Supply the semantics yourself: any list/listitem roles and item labels, and mark
  each row with `ngnScrollerItem`.
- Set `focusable` to put the scroll region in the tab order so it can be scrolled
  by keyboard.
