Splitter divides panels with draggable handles. Each divider is a
`role="separator"` handle that is fully keyboard-operable.

## Keyboard

| Key                                                 | Action                                              |
| --------------------------------------------------- | --------------------------------------------------- |
| `ArrowLeft`/`ArrowUp` (or `ArrowRight`/`ArrowDown`) | Move the divider by one step (axis follows layout). |
| `Home` / `End`                                      | Move the divider to its minimum / maximum.          |

## ARIA & screen readers

The host is `role="region"`. Each divider is a `<button role="separator">` with
`aria-orientation`, a localized `aria-label`, `aria-valuenow` (the leading panel's
size as a percentage), and `aria-valuemin="0"`/`aria-valuemax="100"`. During a
drag, `aria-valuenow` can lag by one change-detection frame.

## Developer responsibilities

- Provide panel sizes (and optional `minSize`/`maxSize`).
- Provide the `splitter_handleLabel` i18n translation — it names each handle.
