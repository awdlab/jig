Meter is presentational: the bar is decoration, and the legend carries the data as
plain text every screen reader can read in document order.

## Keyboard

| Key | Action                                   |
| --- | ---------------------------------------- |
| —   | No keyboard interaction; presentational. |

## ARIA & screen readers

The host is `role="group"` and takes its accessible name from the `label` input.
The bar is `aria-hidden="true"` — it duplicates the legend, which is a plain `<ul>`
of label/percentage text. Legend swatches are `aria-hidden` as well, since color is
never the only carrier of meaning here.

With `showPercentage="false"` each legend entry keeps a visually hidden percentage,
so hiding the numbers is a visual choice only.

The hover pairing between a segment and its legend entry is decorative: it exposes
nothing that the swatch color and the legend text don't already carry, and it is
pointer-only, so keyboard and screen reader users lose nothing when it is off.

## Developer responsibilities

- Set `label` so the group has an accessible name.
- Empty track is silent — no label, no percentage. When the free space matters, pass it
  as an explicit item so it reaches the legend and the accessibility tree.
- Keep item labels meaningful on their own — the segment order and its colors are not
  announced.
- When a custom `#label` template replaces the legend row, make sure it still renders
  the item's label as text.
