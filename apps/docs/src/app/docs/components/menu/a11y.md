Menu implements `role="menu"` with roving focus: menu items are buttons with
`tabindex="-1"` and arrow keys move real DOM focus between them. When the trigger
is a native `<button>`, the control also manages its expansion ARIA.

## Keyboard

| Key                     | Action                                                       |
| ----------------------- | ------------------------------------------------------------ |
| `ArrowDown` / `ArrowUp` | Moves focus between items, wrapping at the ends.             |
| `ArrowRight`            | Opens the focused item's submenu and focuses its first item. |
| `ArrowLeft`             | Closes the current submenu (when inside one).                |
| `Enter` / `Space`       | Activates the focused item (native button).                  |

`Escape` is handled by the popover overlay; there is no `Home`/`End` or typeahead.

## ARIA & screen readers

The container is `role="menu"` (`tabindex="0"`) and items are `role="menuitem"`.
Submenu-parent items expose `aria-haspopup="menu"` and `aria-expanded`. When the
trigger is a native `<button>`, the control auto-sets `aria-controls`,
`aria-haspopup="menu"`, and `aria-expanded` on it. Closing a submenu returns focus
to its parent item.

## Developer responsibilities

- Provide an accessible name for the trigger.
- For non-`<button>` triggers, enable `autoAnchorAria` or wire the trigger ARIA
  yourself — auto ARIA is applied only for native buttons.
- Provide a label for each menu item.
