### Roles & Attributes

The directive adds no roles or ARIA attributes. The shadows are purely
decorative: they are painted by an empty overlay `<div>` inserted as the scroll
container's first child, which carries no text, is not focusable and ignores
pointer events, so assistive technology has nothing to announce.

The shadow is only a visual hint that more content exists. Do not rely on it to
convey information — anything a user needs must be reachable by scrolling
regardless of whether the shadow shows.

### Keyboard Interaction

**Unchanged.** The directive never intercepts input, so the scroll container
scrolls with the keyboard exactly as it would without it. If the container
itself has no focusable content, give it `tabindex="0"` (and an accessible name)
so keyboard users can focus and scroll it.
