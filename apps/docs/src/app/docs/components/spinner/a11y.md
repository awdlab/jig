The spinner renders with `role="status"`, so assistive tech treats it as a polite
live status region.

## Keyboard

| Key | Action                                   |
| --- | ---------------------------------------- |
| —   | No keyboard interaction; presentational. |

## ARIA & screen readers

The host is `role="status"` (an implicit polite live region). The spinner itself
sets no `aria-label`. When shown via the programmatic creator, it sets
`aria-busy="true"` on the target element while active (opt out with
`ariaBusy: false`).

## Developer responsibilities

- Provide a meaningful loading message/label — a bare spinner announces as an
  empty status region.
