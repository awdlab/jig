The Radio component lets the user pick a single option from a set. Compose
`ngn-radio` options inside an `ngn-radio-group`; the group owns the selected
value while each option contributes its payload.

Selection follows focus — arrow keys move between options and select as they go,
matching native radio-group behavior. The group is a single tab stop and lands
on the checked option.
