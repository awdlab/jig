Radio implements the ARIA radio group pattern as custom-role widgets:
`ngn-radio-group` is `role="radiogroup"` and each `ngn-radio` is `role="radio"`.
Selection follows focus — arrow keys move both.

## Keyboard

| Key                                                 | Action                                                                                                |
| --------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `ArrowRight`/`ArrowLeft` (or `ArrowDown`/`ArrowUp`) | Move focus and selection to the previous/next enabled radio. Axis depends on the group's orientation. |
| `Home` / `End`                                      | Select the first / last enabled radio.                                                                |

Movement wraps only when `rovingWrap` is enabled; disabled radios are skipped.

## ARIA & screen readers

The group is `role="radiogroup"` with `aria-label`/`aria-labelledby`,
`aria-orientation`, `aria-invalid="true"` when invalid, and `aria-disabled` when
disabled. Each radio is `role="radio"` with `aria-checked`, `aria-disabled`, and
an `aria-label` from its `label` input. A roving tabindex keeps a single tab stop
on the selected radio.

## Developer responsibilities

- Give the group an accessible name via `label` or `labelledBy` (neither is set
  by default).
- Each `ngn-radio` needs a `value` and an accessible name — projected text
  content or the `label` input.
