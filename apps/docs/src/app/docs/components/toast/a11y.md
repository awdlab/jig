Toasts are live-region notifications following the WAI-ARIA notification pattern.
Politeness derives from the toast's color (like snackbar), or set it explicitly
with `ariaLive`.

## Keyboard

| Key                     | Action                             |
| ----------------------- | ---------------------------------- |
| `Escape`                | Dismiss a closable toast.          |
| `F6`                    | Jump focus to the newest toast.    |
| `ArrowUp` / `ArrowDown` | Move between toasts in the region. |
| `Home` / `End`          | Focus the first / last toast.      |

## ARIA & screen readers

Each toast is `role="alert"` with `aria-live="assertive"` for `error`/`warning`
colors, otherwise `role="status"` with `aria-live="polite"`; `aria-atomic="true"`
is always set. An explicit `ariaLive` (`polite`/`assertive`/`off`) overrides the
color-derived politeness. The close button has a localized `aria-label` and its
icon is `aria-hidden`. The container is a labelled `role="region"` with a roving
tabindex. The auto-hide timer pauses whenever a toast is hovered or focused (WCAG
2.2.1) so it cannot vanish while being read.

## Developer responsibilities

- Politeness derives from `color`; override it with `ariaLive` when a toast should
  announce more or less urgently than its color implies.
- Provide the toast i18n strings (close label, region label).
- Focus returns to the previously focused element automatically on close.
