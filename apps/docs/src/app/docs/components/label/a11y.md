### Roles & Attributes

The directive adds no roles. It sets `for` on the label, an `id` on the label
(unless it has one), and adds that id to the target's `aria-labelledby` — native
inputs included. Existing `aria-labelledby` ids on the target are kept, and the
label's id is removed again when the label goes away.

### Keyboard Interaction

None. Labels are not focusable; the directive only reacts to pointer clicks.

### Accessible name

`aria-labelledby` wins over the control's own `label` input (`aria-label`), so
the visible label text is what assistive technology announces — satisfying
[WCAG 2.5.3 Label in Name](https://www.w3.org/WAI/WCAG22/Understanding/label-in-name.html).
