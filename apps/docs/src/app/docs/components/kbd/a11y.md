`jig-kbd` renders a native `<kbd>` element, which assistive technology announces as
keyboard input.

An action button configured with a `shortcut` sets `aria-keyshortcuts` to the ARIA
key names for the combo (e.g. `Control+S`, not `ctrl+s`), so screen readers can
announce the binding. Icon-only buttons keep the plain label as their tooltip and
accessible name; the glyphs render inline next to the icon, hidden from assistive
tech.

Shortcuts never replace a visible control: every `[ngnKeyboardShortcut]` binding in
the library is a shortcut _to_ a focusable button, not the only way to reach an action.
