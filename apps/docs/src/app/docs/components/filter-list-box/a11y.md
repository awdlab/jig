Filter List Box composes a search field, an optional filter trigger with
condition chips, and a list box; the list keeps the list box's `role="listbox"`
and `aria-activedescendant` behavior.

## Keyboard

| Key                     | Action                                                         |
| ----------------------- | -------------------------------------------------------------- |
| `Tab`                   | Move between the search field, trigger, chip buttons and list. |
| `Enter` / `Space`       | Activate the filter trigger or a chip's remove button.         |
| `ArrowDown` / `ArrowUp` | Move the highlight within the list (see list box).             |

Navigation within the filter popover is handled by the attribute filter.

## ARIA & screen readers

- **Search field** — the input has a localized `aria-label`
  (`filterListBox.search`).
- **Filter trigger** — an icon button whose `aria-label` is the localized
  `filterListBox.openFilter`, with the active condition count appended in
  parentheses. The badge itself is decorative and kept out of the name.
- **Chips** — the row is a `role="group"` labelled `filterListBox.activeFilters`.
  Each chip shows its condition as text; its remove button is labelled with the
  `chip.close` string ("Remove"), which does not repeat the condition.
- **List** — the embedded list box takes `label` / `labelledBy`.
- **Empty state** — the list box's `role="status"` empty state, including the
  "Clear all filters" button.

When `disabled` or `readonly`, the filter trigger is disabled and the chips lose
their remove buttons.

## Developer responsibilities

- Provide `items`, and `attributes` if the filter should exist.
- Give the list an accessible name via `label` or `labelledBy`.
- Give each attribute a human-readable `label` — it appears in the chips.
- Supply the filter list box, attribute filter, filter and chip i18n
  translations.
