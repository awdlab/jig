# @ngneers/controls-custom-types

**Shared TypeScript type contracts for
[@ngneers/controls](https://www.npmjs.com/package/@ngneers/controls).**

[![Main package](https://img.shields.io/badge/Main%20package-%40ngneers%2Fcontrols-e90464?style=for-the-badge)](https://www.npmjs.com/package/@ngneers/controls)
[![Documentation](https://img.shields.io/badge/Documentation-ngneers.dev-8514f5?style=for-the-badge)](https://ngneers.dev)

</div>

Type definitions only (icon and token contracts) that both the controls and the themes
depend on, so the two packages stay in lockstep without a runtime dependency between them.

You normally don't install this directly — it arrives as a transitive dependency of
`@ngneers/controls`. Install it explicitly only to augment the contracts (e.g. declaring
your own icon keys).
