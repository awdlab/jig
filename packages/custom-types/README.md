# @awdlab/jig-custom-types

**Shared TypeScript type contracts for
[@awdlab/jig](https://www.npmjs.com/package/@awdlab/jig).**

[![Main package](https://img.shields.io/badge/Main%20package-%40awdlab%2Fjig-e90464?style=for-the-badge)](https://www.npmjs.com/package/@awdlab/jig)
[![Documentation](https://img.shields.io/badge/Documentation-jig.awdlab.dev-8514f5?style=for-the-badge)](https://jig.awdlab.dev)

</div>

Type definitions only (icon and token contracts) that both the controls and the themes
depend on, so the two packages stay in lockstep without a runtime dependency between them.

You normally don't install this directly — it arrives as a transitive dependency of
`@awdlab/jig`. Install it explicitly only to augment the contracts (e.g. declaring
your own icon keys).

## Documentation
